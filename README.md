# OpenSourceScout

A local-first AI engineering assistant for discovering, evaluating, and completing
high-quality open-source contributions.

> **Status:** early development. Foundation and GitHub discovery are implemented;
> issue intelligence, LLM reasoning, execution, and the PR workflow are not yet built.
> See [docs/progress.md](docs/progress.md) for exact status.

Full documentation (architecture, installation, configuration, safety model) will land
as each phase is built. See [docs/architecture.md](docs/architecture.md) in the
meantime.
